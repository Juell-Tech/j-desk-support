Juell-Tech Support Host

Remote help for your PC, only when you allow it

Download for Windows

Works on Windows 7 and later, including Windows Server 2008 R2.

Install (about two minutes)

  1. Run the file you downloaded. If Windows shows a blue “Windows protected your PC” box, choose More info, then Run anyway.
  2. Choose Yes when Windows asks for permission.
  3. Enter your company name. The PC name is filled in for you; change it if you like (for example “Reception”).
  4. Press Next and Install. A round red J-Desk icon appears near the clock (it may be under the ^ arrow).

Ask for support

  1. Click the J-Desk icon near the clock (right-click on some PCs).
  2. Choose how you want to be helped:
    • Instant Temporary Support: for one session. Their access ends when the session ends.
    • Ongoing Support: they can connect again later without asking, until you choose Stop support.
  3. Choose Get support: show my host ID to send. The ID is copied; send it to your support company by email or message.
  4. When they connect, a box asks Allow it? Choose Yes only if you are expecting them.

Stop support or remove it

Click the icon and choose Stop support at any time. To remove the program, use Windows Settings > Apps > Installed apps > Juell-Tech Support Host > Uninstall.

Questions? Contact your support company, or Juell-Tech at the address they gave you.
