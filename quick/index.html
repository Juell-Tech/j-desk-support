Juell-Tech Quick Support

Let us help you on your PC. Nothing is installed.

Download Quick Support

Windows 7 and later, including Windows Server 2008 R2. About 13 MB.

What to do

  1. Press Download Quick Support above, then open the file it downloads. If Windows shows a blue “Windows protected your PC” box, choose More info, then Run anyway.
  2. Choose Yes when Windows asks for permission.
  3. A small window says Ready. Leave it open and let us know you are ready. If it asks for a code, type this one: (your code)
  4. When we connect, a box asks Allow it? Choose Yes only if you are expecting us.

You stay in charge

  • Nothing happens until you press Yes on the box that appears when we connect.
  • Press End support in the small window at any time to stop. Everything is removed when it closes: nothing stays on your PC.
  • This link only works for 24 hours.
